# 🔍 Système de Recherche CV

## 📝 Description
Interface de recherche avancée pour les CVs avec support multi-mots-clés et filtres personnalisés.

## 🚀 Accès rapide
**URL principale :** `http://localhost/CV_Generator/cv_search_system/cv_search_interface.html`

## 📁 Structure des fichiers
- `cv_search_interface.html` - Interface utilisateur principale
- `search_handler_mvc.php` - Handler MVC pour les requêtes de recherche
- `cv_search_system.php` - Système de recherche (legacy)
- `cv_search_config.php` - Configuration du système
- `index.html` - Page d'accueil du module

## ⚡ Fonctionnalités
- ✅ Recherche multi-mots-clés avec guillemets
- ✅ Filtres par ville et compétences
- ✅ Statistiques en temps réel
- ✅ Interface responsive
- ✅ Aperçu des CVs en modal
- ✅ Export et partage des résultats

## 🔧 Configuration XAMPP
Pour que le système fonctionne automatiquement :

1. **Ouvrir XAMPP Control Panel**
2. **Cocher "Svc" pour Apache et MySQL**
3. **Cliquer "Install" pour les deux services**
4. Les services démarreront automatiquement avec Windows

## 🎯 Exemples d'utilisation
- Recherche simple : `java`
- Recherche multi-mots : `"java" "mysql" "react"`
- Avec filtres : mot-clé + ville + compétences

## 📊 Base de données
- Database : `cv_craft`
- Table principale : `cvs`
- Structure adaptée automatiquement
